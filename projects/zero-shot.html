Zero-shot image classification on AwA2

2025 → rebuilt 2026Python · PyTorch · ResNetSource on GitHub

Problem

A conventional classifier can only predict classes it was trained on. Zero-shot learning recognises new classes from a description: here, the 85 semantic attributes of Animals with Attributes 2 ("striped", "aquatic", "has hooves"). The model trains on 40 classes and is tested on 10 it has never seen.

Approach

  • Standard protocol. Proposed Split (Xian et al., 2018), whose unseen classes are disjoint from ImageNet-1k so the pretrained backbone can't leak them. Load-time checks fail if any unseen image reaches training.
  • Honest model selection. Hyper-parameters are chosen on 13 validation classes disjoint from the 27 training classes, imitating the test condition. The test set is touched once.
  • GZSL calibration. Calibrated stacking subtracts γ from seen-class scores to counter the bias toward training classes; γ is tuned on validation only.

Auditing my own earlier number

My 2025 paper reported 90.48% accuracy. The original code is lost, so I tested what that number is consistent with, on the same data:

MeasurementResult
Standard zero-shot accuracy (this project)59.0%
Conventional 40-way classification of seen classes92.7% per-class / 94.5% overall
Zero-shot on random, non-standard class splits64–85%
Binary seen-vs-unseen detection72.6% (AUROC 0.84)

The paper used a custom split, reported binary-classification metrics and compared against out-of-distribution detectors. 90.48% matches conventional or non-standard-split accuracy, not standard zero-shot performance, so I treat it as unverified and report 59.0%.

Engineering

Independent modules (features, semantic, model, train, metrics, inference), YAML config, checkpoints, deterministic training enforced by a test, 14 tests and CI; runs on CPU in about a minute.
